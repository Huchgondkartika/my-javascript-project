## Project Description

This repository contains a collection of JavaScript mini projects developed using HTML, CSS, and JavaScript. These projects focus on logic building, DOM manipulation, and working with APIs through hands-on practice.

The projects included in this repository allow users to:
- Play interactive browser-based games
- Understand JavaScript logic and conditions
- Work with DOM elements and events
- Fetch and display data from external APIs

This repository demonstrates:
- JavaScript fundamentals
- DOM manipulation
- Event handling
- Asynchronous JavaScript (Fetch API)
- Basic front-end development concepts
